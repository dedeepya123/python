# 02 - Python Classes, Objects and the Type Hierarchy

## Prerequisite

From the previous note:

```text
Everything in Python is an object.

Object:
    - Value
    - Type
    - Identity

Variable:
    A name bound to an object.

Reference:
    A link between a variable name and an object.
```

Now the natural question is:

> If everything is an object, then every object must be an instance of some class.
>
> So what class does an object belong to?
>
> Where do its methods and attributes come from?

# Classes Define Attributes and Methods

Consider:

```python
s = "hello"

s.upper()
```

Question:

> Where did the `upper()` method come from?

Answer:

```text
The class str defines upper().
```

Mental Model:

```text
Object: "hello"

Instance Of
     │
     ▼

Class: str

    upper()
    lower()
    split()
    replace()
    strip()
```

When Python sees:

```python
s.upper()
```

it looks for `upper()` on the object's class.

---

Mental Model:

# User Defined Classes

We can create our own classes.

```python
class Person:
    def greet(self):
        print("Hello")
```

Create an object:

```python
p = Person()
```

Check its type:

```python
print(type(p))
```

Output:

```python
<class '__main__.Person'>
```

Mental Model:

```text
p
│
▼
Person Object
│
▼
Person Class
```

The object gets its methods from the class.

```python
p.greet()
```

Output:

```python
Hello
```

---

# The Root of All Classes: object

A surprising fact:

Almost every class in Python ultimately inherits from a class called:

```python
object
```

Example:

```python
class Person:
    pass

print(Person.__mro__)
```

Output:

```python
(<class '__main__.Person'>,
 <class 'object'>)
```

Mental Model:

```text
object
   ▲
   │
Person
   ▲
   │
p
```

---

# Why Does Every Object Have Common Methods?

Try:

```python
x = 10

print(x.__str__())
print(x.__repr__())
```

or

```python
s = "hello"

print(s.__str__())
```

These methods are available because all classes ultimately derive from:

```text
object
```

The `object` class provides common behavior that every Python object can use.

# What is type?

`type` is the class responsible for creating classes.

Just as:

```python
Person()
```

creates Person objects,

```python
type(...)
```

creates class objects.

Think of it as:

```text
Object Factory     -> Class
Class Factory      -> type
```

Mental Model:

```text
Object
   ▲
   │ created by
   │
Class
   ▲
   │ created by
   │
type
```
